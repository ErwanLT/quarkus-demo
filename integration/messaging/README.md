# Messaging

Ce module regroupe les tutoriels d'integration bases sur des messages, des notifications et des flux d'evenements.

## [Server-Sent Events - panneau magique](sse-tutorial)
Tutoriel SSE avec Quarkus RESTEasy Reactive et Mutiny.
Le panneau magique garde les aventuriers connectes et diffuse chaque cri du barman sans polling cote client.

## [Corbeaux messagers - Kafka](kafka-tutorial)
Tutoriel d'intégration avec Apache Kafka (Redpanda) et SmallRye Reactive Messaging.
Découvrez comment mettre en place une volière asynchrone complète incluant les mécanismes de tentatives (**Retry**) et de redirection vers la file d'attente des messages en échec (**Dead Letter Queue / DLQ**).
