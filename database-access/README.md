# Database Access

Ce module regroupe les tutoriels sur l'accès aux données avec Quarkus.

## [Hibernate Panache](panache-tutorial)
Tutoriel sur l'utilisation de **Hibernate Panache** pour simplifier l'accès aux bases de données SQL via le pattern Active Record ou Repository.

## [Le registre des travaux (Flyway & Liquibase)](flyway-liquibase-tutorial)
Tutoriel comparatif sur les **migrations de schéma** avec Flyway et Liquibase : scripts versionnés, baseline d'une base existante, triptyque expand/backfill/contract et validation du schéma par Hibernate.
